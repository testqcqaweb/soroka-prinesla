# Сдача текста

Перед отправкой паре:

1. Имена, даты, города — как в брифе, без опечаток.
2. Текст читается вслух за запланированное время (речь 4–7 мин, стих не сбивает дыхание).
3. Нет канцелярита («от всей души поздравляем», «совет да любовь» как заглушка).
4. Есть 2–3 живые детали из брифа, которые узнает только эта пара.
5. Одна страница «как читать»: темп, паузы, где смотреть в зал.
6. Форматы: `.docx` и `.pdf`. Имя файла: `soroka-фамилия-дата-речь.pdf`.
7. Напомнить: одна правка в цене, правки после сдачи пакета — по договорённости.

Оферта-коротыш для чата:

«Пишу [пакет] за [сумма]. Срок 5–10 дней после предоплаты 50% и брифа. В цене одна правка. Остаток до отправки файла. Не публикую ваш текст и не отдаю третьим лицам.»
